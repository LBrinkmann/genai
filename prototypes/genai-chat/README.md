# GenAI Chat

A simple React chat application with a dark theme, built with Vite and Tailwind CSS.

## Features

- **Dark theme** – Black background with zinc accents
- **Chat interface** – Message input, send button, and message history
- **Tailwind CSS** – Utility-first styling
- **Responsive layout** – Works on different screen sizes

## Getting Started

Install dependencies (if needed):

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
